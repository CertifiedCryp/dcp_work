Round 1 — brainstorm by mechanism.

(i) Review-grade 2^{c sqrt n} for every N.
 M1 (current): CRT split N = 2^e N_odd. For the 2-part: 2-adic sieve to label 2^{e-1}, then the exact coset-state Hensel lift, e times. For the odd part: rejection-uniform interval sieve in relabelled frames a = 2^{-j}, then Kitaev reconstruction. Mechanistically distinct pieces: exact Hensel lift (no rotations), uniformity restoration by rejection, frame relabelling.
 M2: single uniform method for all N. Use the interval sieve for every N (it never uses subgroups), with frames a = 2^{-j} only when gcd(2,N) = 1. For even N, use the Hensel lift to remove the 2-part first. This is M1 without the 2-adic sieve, so only one sieve analysis is needed. Simpler to prove, so prefer M2.
 M3: avoid QFT_N entirely. Use phase estimation of the modular shift operator with an m-qubit dyadic register; every operation except the dyadic rotations is an exact reversible circuit. It is still approximate, so it doesn't escape gate synthesis. Superficial difference; not worth it unless citing QFT_N proves awkward.
 M4: replace "exact final label 1" with "small known label k, |k| <= K, gcd conditions". This does not work with Kitaev reconstruction (it would need frac(2^j k s/N) for unknown products). Discard.

(ii) Corruption tolerance.
 T1: leaf-disjoint trees plus majority (counting lemma). Gives eps of about yield/(3(d+2)).
 T2: shallow sieves, d = a log n. Trade-off T = 2^{n/log(1/eps)}.
 T3 (mechanistically new?): verification-based aggregation. Generate many candidate s values from cheap, short sieves. Verify each candidate with the exhaustive shift test using fresh copies: wrong candidates fail each test with probability 1/2. Adversarial copies can make the correct candidate fail a test, but only if they land in its test. Randomize which copies go to which tests and use thresholds. This might decouple tolerance from tree size: you only need one correct candidate among the generated ones and a robust verifier. A correct candidate still requires a fully clean reconstruction (n+2 frames each with clean outputs), so it doesn't escape the tree-size issue. It might reduce the constant or log factors only.
 T4: error-correcting combination. A phase qubit with a corrupted subtree produces an arbitrary output, so information-theoretically tolerance must be at most about 1/L for outputs depending on L copies. Unless outputs depend on few copies, tolerance is low. The trade-off in T2 may be essentially tight within collision sieves. Possible lemma: any algorithm in which each measured bit depends on at most L copies, and which needs at least one correct output per stage...

(iii) Beating sqrt(n).
 A1: r-way combinations (parity of r qubits) give labels sum of eps_i k_i with known random signs. Generalized birthday with forced random signs behaves like Wagner with a constant-factor loss, so no change in exponent.
 A2: multi-frame relabelling. One set of copies can be viewed in many frames a, and a collision in any frame is usable. That gives up to N frames, but different frames are just unit multiples. For random labels, the number of frames in which a pair collides is the same in expectation, so there's no amplification beyond ~n bits. Superficial.
 A3: use the sum outcome (k1+k2) as well, by bucketing a label with the negatives of others. This doubles yield per level, changing constants only.
 A4: Regev-style lattice reduction in the reverse direction (DCP -> LWE-type -> BKW with better exponents?). BKW for LWE is 2^{O(n/log n)}, which is worse.
 Honest conclusion so far: no mechanism I can see beats sqrt n. The n^{1/3} question looks like it needs a new non-sieve primitive.
