Round 3 — long-term plan and first tests.

Checking M2' once more: the frame trick needs the final label to be exactly 1 in frame a. Sieve inputs in frame a are labels a·k mod N, which are still i.i.d. uniform on Z_N because multiplication by a unit is a bijection. So the uniformity analysis is frame-independent. Fine. The sign flip by X handles negative final labels. The final range {-1,0} -> label -1 w.p. exactly 1/2 under uniformity, and label 0 is discarded. Interval sieve parameters: initial range of length R_0 = W_0 2^{b_0} <= N (dyadic prefix), then d levels each dividing the range length by 2^b, ending at length 2. List size L_l at level l needs L_l >= 2^{b+?} for the pigeonhole yield. The yield per level is >= (L - 2^b)/2 pairs × 1/2 (CNOT) × ~1/2 (rejection). With L_{l+1} >= L_l/16 when L_l >= 2^{b+1}: L_0 = 16^d 2^{b+1} F with d·b ≈ n gives time 2^{4d + n/d} → d = sqrt(n)/2, exponent 4 sqrt n. Explicit constant around 4 (plus lower-order terms). Rejection and CNOT outcomes are random, so yields need Chernoff bounds with explicit failure probabilities, or an "abort-on-shortfall" cutoff giving worst-case resource bounds and a failure probability bounded via Chernoff.
