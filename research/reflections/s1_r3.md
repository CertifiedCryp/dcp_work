Re-examining round 2:
(1) Rejection-sampling uniformity. For integer W even and u1, u2 i.i.d. uniform on {0..W-1}: P(v) = (W-|v|)/W^2. On the target set T = {-W/2, ..., W/2-1}, accept with p(v) = (W/2)/(W-|v|). This is in (0,1] since |v| <= W/2 on T. Then P(v, accept) = 1/(2W) is constant on T, so the conditional is uniform on T and P(accept) = 1/2. Values in the next level's buckets need the range length divisible by the bucket count. Keep every range length a power of two after the first level. At the first level, discard labels outside the largest dyadic-multiple prefix of [0, N); the loss is a constant fraction if the first bucket width is <= N/2. This looks sound. I must also check that the pairing order is independent of within-bucket offsets (pair by acquisition index inside a bucket). It is, because the bucket index depends only on the high part, and the within-bucket offset is independent of the bucket index for i.i.d. uniform labels on a range partitioned into equal intervals.
Coins: p(v) has denominator W - |v|, which is not dyadic. Use lambda random bits and accept iff U < floor(2^lambda p(v)) / 2^lambda. Per decision the law of the accepted value deviates by O(2^{-lambda}/p_min) in TV. A union bound over all decisions with lambda = 2 sqrt n + O(log n) bits is enough. Alternatively, make acceptance exact by using the triangular law's own structure: draw a fresh uniform r in {0..W-1} and accept iff r < W/2 ... I could not find a clean exact dyadic version, so truncation with a TV budget it is.
(2) Tolerance trade-off. The counting argument needs each final output tree to be disjoint in leaves. It is in a sieve, which consumes copies. The bounds "B contaminated outputs, plus at most d·B lost clean outputs" need care: a bad label can also be placed so that pigeonhole pairing fails for a good label, but a good label left unpaired is just one lost subtree. So the bound is plausible. With a declarable tolerance of 1/n^a I need yield F/Q >= 3(d+2)/n^a, i.e. F/Q of about 1/poly. The sieve yield per level is about 1/8 (times the pigeonhole slack). With d levels, the yield is about 8^{-d} = n^{-3a'}, so d = a' log2 n and each level clears n/d bits. Bucket count 2^{n/d} means lists of at least 2·2^{n/d}, so time is 2^{n/(a' log2 n) + O(log n)}. This is index 1, but its full bound beats exhaustive search, and it comes with declared tolerance. For the main index-1/2 claim, tolerance must be declared as 0 (2^{-sqrt n} is not expressible). Both are legitimate Pareto points.
