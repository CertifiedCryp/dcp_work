Round 2 — I found an error in my own Stage 1, and it simplifies the design.

Error: in Stage 1 I claimed that x -> x mod m maps rho_s to an exact Z_m coset state, so CRT is free. That is wrong. Computing x mod m and discarding the rest traces out the high part of the register. In the two branches |0,x> and |1,x+s> the high parts differ, so the trace destroys the interference and leaves a mixed state with no information. A sanity check exposes it: if it worked, combined with the Hensel lift, DCP over Z_{2^n} would be solvable in polynomial time.
What is valid is a conditional Hensel lift. If s ≡ r (mod m) is already known for some m | N, controlled-subtract r on the |1> branch. Now x and x+s-r agree mod m, so measuring x mod m is coherent. The residual is an exact coset state over Z_{N/m} with secret (s-r)/m. Arithmetic structure only helps after a residue has been learned, and learning a residue still needs Fourier labels that are multiples of N/m, which is exactly what sieves produce. Lesson for R3: check every arithmetic shortcut against the polynomial-time sanity test.

Simplification (M2'): avoid CRT and the 2-adic sieve entirely. Pick a small prime g with g ∤ N. At most n distinct primes divide N < 2^n, so one of the first n+1 primes works. Use g as the base of a generalized Kitaev reconstruction:
 - theta_j = frac(g^j s / N) for j = 0..m-1, m = ceil(log_g N) + 2.
 - theta_j ∈ {(theta_{j+1} + r)/g : r = 0..g-1}. Pick the candidate closest to an estimate alpha_j with circular error < 1/(4g). This keeps the error at 2^{-?}/g-scale shrinking backwards, and at the end s = round(N theta_0).
 - Labels g^j come from a frame a = g^{-j} mod N (an invertible unit): sieve to final frame label 1.
 - Estimating theta_j to within 1/(4g) needs O(g^2 log m) Hadamard-test copies. With g <= (n+1)^2 this is poly(n) (I need a citable bound such as Rosser-Schoenfeld p_k < k(ln k + ln ln k) for k >= 6, or simply search g by trial division, whose cost is polynomial).
 For N = 2^n, g = 3. One sieve analysis (rejection-uniform intervals) covers every N. This is cleaner and closer to my identity: the unit group (Z/N)^* is the tool.
 Even better: the reconstruction only needs alpha_j accurate to 1/(4g), so I could estimate with X/Y Hadamard tests and Hoeffding using explicit constants.

Tolerance revisited: in M2' the final outputs per frame j are F_j phase qubits with label g^j. Majority/median over estimates of theta_j is robust if bad outputs are at most a small fraction of F_j. The counting lemma applies per frame, with copies acquired fresh per frame. So eps can be set by the worst frame yield.

T3 (verification) does not change exponents; drop it. T4: the upper limit of about 1/L tolerance for outputs that depend on L copies looks like a genuine structural limitation, worth stating as a remark (not a theorem) unless I can prove it.
